Для обучения точек открытия/закрытия полки надло выполнять программу по шагам до нужных точек, обучить точки и выполнить далее. При этом когда полка закрыта, мы обучаем первую точку открытия посередине паза и вторую точку закрытия на ближнем к ячейке краю паза (Z+), когда полка открыта, обучаем первую точку закрытия в середине паза и вторую точку открытия на дальнем краю паза (Z-)
Напиши инструкцию
.PROGRAM shelf.teach ()
    ;
  ; Preaprations for teaching
  TOOL tool.pin
  SIGNAL grip.close[1], -grip.open[1]
  SIGNAL grip.close[2], -grip.open[2]
  JMOVE #shelf.safe
  ;
  ; Teach points for open shelf
  LMOVE shelf.open[hmi.shelf.no, 1] + TRANS (-50, 0, -150)
  LMOVE shelf.open[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
  BREAK
  ; Teach this point for shelf open
  LMOVE shelf.open[hmi.shelf.no, 1] ; **== TEACH POINT ==**
  ; Teach this point for shelf close
  LMOVE shelf.close[hmi.shelf.no, 2] ; **== TEACH POINT ==**
  ;
  LMOVE shelf.open[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
  LMOVE shelf.open[hmi.shelf.no, 1] + TRANS (-50, 0, -150)
  JMOVE #shelf.safe
  ;
  ; Teach points for close shelf
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (150, 0, -150)
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (-50, 0, -150)
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
  BREAK
  ; Teach this point for shelf close
  LMOVE shelf.close[hmi.shelf.no, 1] ; **== TEACH POINT ==**
  ; Teach this point for shelf open
  LMOVE shelf.open[hmi.shelf.no, 2] ; **== TEACH POINT ==**
  ;
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (-50, 0, -150)
  LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (150, 0, -150)
  JMOVE #shelf.safe
  ;
.END

# Обучение точек открытия и закрытия полки

## 1. Подготовка

Перед началом обучения убедитесь, что робот находится в безопасном положении, а полка установлена и доступна для обучения.

Запустите программу:

```text
.PROGRAM shelf.teach ()
```

Программа автоматически выполнит подготовительные операции:

```text
TOOL tool.pin
SIGNAL grip.close[1], -grip.open[1]
SIGNAL grip.close[2], -grip.open[2]
JMOVE #shelf.safe
```

**Выполнять эти строки вручную не требуется.**

---

## 2. Обучение точек при открытой полке

Откройте полку.

Запустите выполнение программы по шагам и остановитесь после строки:

```text
LMOVE shelf.open[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
BREAK
```

Робот должен находиться в положении перед первой точкой обучения.

### Точка 1 — открытие полки

Следующая строка:

```text
LMOVE shelf.open[hmi.shelf.no, 1] ; **== TEACH POINT ==**
```

Обучите эту точку **в середине паза полки**.

Это первая точка движения для **открытия полки**.

После обучения выполните программу далее.

### Точка 2 — закрытие полки

Следующая точка:

```text
LMOVE shelf.close[hmi.shelf.no, 2] ; **== TEACH POINT ==**
```

Обучите эту точку **на дальнем от ячейки краю паза (Z−)**.

Это вторая точка движения для **закрытия полки**.

После обучения выполните программу далее до безопасного положения:

```text
JMOVE #shelf.safe
```

---

## 3. Обучение точек при закрытой полке

Закройте полку.

Снова запустите программу:

```text
shelf.teach
```

Выполняйте программу по шагам и остановитесь после строки:

```text
LMOVE shelf.close[hmi.shelf.no, 1] + TRANS (-50, 0, 0)
BREAK
```

Робот должен находиться в положении перед первой точкой обучения.

### Точка 1 — закрытие полки

Следующая строка:

```text
LMOVE shelf.close[hmi.shelf.no, 1] ; **== TEACH POINT ==**
```

Обучите эту точку **в середине паза полки**.

Это первая точка движения для **закрытия полки**.

После обучения выполните программу далее.

### Точка 2 — открытие полки

Следующая строка:

```text
LMOVE shelf.open[hmi.shelf.no, 2] ; **== TEACH POINT ==**
```

Обучите эту точку **на ближнем к ячейке краю паза (Z+)**.

Это вторая точка движения для **открытия полки**.

После обучения выполните программу далее до:

```text
JMOVE #shelf.safe
```

---

## 4. Итоговое расположение точек

При **открытой полке**:

| Точка                 | Назначение | Положение             |
| --------------------- | ---------- | --------------------- |
| `shelf.open[... ,1]`  | Открытие   | Середина паза         |
| `shelf.close[... ,2]` | Закрытие   | Дальний край паза, Z− |

При **закрытой полке**:

| Точка                 | Назначение | Положение                      |
| --------------------- | ---------- | ------------------------------ |
| `shelf.close[... ,1]` | Закрытие   | Середина паза                  |
| `shelf.open[... ,2]`  | Открытие   | Ближний к ячейке край паза, Z+ |

### Важно

Две точки каждой операции обучаются **последовательно, без промежуточного движения между ними**.

Не изменяйте автоматически выполняемые строки программы:

```text
TOOL tool.pin
SIGNAL grip.close[1], -grip.open[1]
SIGNAL grip.close[2], -grip.open[2]
```

Они выполняются программой автоматически перед обучением точек.
